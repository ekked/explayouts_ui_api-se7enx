netgen-layouts.js

The application bundle of the Netgen Layouts editor, built from netgen/layouts-ui
2.0.0 (bundle/Resources/public/js/netgen-layouts.js,
https://github.com/netgen-layouts/layouts-ui), and patched for Exponential:
it translates its texts through nglT(), and its rich text and code editors are
provided by explayouts-tiptap.js. It uses no jQuery: jQuery, jQuery UI,
Bootstrap's JavaScript, Moment.js and eonasdan-bootstrap-datetimepicker are no
longer part of it, nor loaded by the page; the DOM layer that stands in for
jQuery, the drag and drop, dialogs, panels, menus and dates are code of this
extension (src/app-patches/modules/).

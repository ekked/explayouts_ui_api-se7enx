netgen-layouts.js

The application bundle of the Netgen Layouts editor, built from netgen/layouts-ui
2.0.0 (bundle/Resources/public/js/netgen-layouts.js,
https://github.com/netgen-layouts/layouts-ui), and patched for Exponential:
it uses the page's jQuery and jQuery UI (ezjscore), translates its texts through
nglT(), and its rich text and code editors are provided by explayouts-tiptap.js.
